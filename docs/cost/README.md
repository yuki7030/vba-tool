# コスト測定記録

`/cost-audit`(`.github/skills/cost-audit/`)が出力する測定報告書の置き場。
`YYYY-MM-DD.md` の形式で蓄積する。手で書かない。

`docs/audit/`(指示ファイルの監査記録)とは目的が違うため分けている。
あちらは指示ファイルの品質、ここはトークン/クレジット消費の実測。

## 読み方

- **T0**(常駐)は絶対値の閾値を持たない。**前回測定との差**で判断する。
  比較対象がここにあるので、報告書を消すと判断材料が消える。
- **T1**(作業)は範囲で記録される。対処前後の範囲が重なっていれば効果なし。
- 効果検証が「測定不能」の対処は、効いた証拠が無いまま入っている。
  次の測定で基準タスクを拡張できないか検討する。

判定基準は `.github/skills/cost-audit/references/benchmark.md`。
